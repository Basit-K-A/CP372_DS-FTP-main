# CP372: Data Structures & FTP Implementation

A Java-based implementation of data structures and File Transfer Protocol (FTP) functionality, developed as part of the CP372 course.

## Overview

This project demonstrates the practical application of data structures in implementing an FTP client/server system. It combines fundamental computer science concepts with network programming to create a functional file transfer solution.

## Features

- **Data Structures**: Implementation of various data structures for efficient data management
- **FTP Protocol**: File Transfer Protocol implementation for secure file exchanges
- **Java-based**: Built entirely in Java for platform independence and robustness

## Requirements

- Java 8 or higher
- JDK (Java Development Kit)

## Installation

1. Clone the repository:
```bash
git clone https://github.com/Basit-K-A/CP372_DS-FTP-main.git
```

2. Navigate to the project directory:
```bash
cd CP372_DS-FTP-main
```

3. Compile the Java source files:
```bash
javac src/*.java
```

## Usage

```bash
java -cp src/ <MainClassName>
```

Replace `<MainClassName>` with the appropriate main class for your use case.
